진행한 프로젝트

스마트 베이커리 모니터링 & 채팅 연동 시스템

Raspberry Pi
Flask
WinForm
C
JSON

라즈베리파이 4대를 이용해 오븐, 냉동고, 포장 구역에 카메라와 센서를 설치하고, Flask 서버를 통해 영상과 데이터를 PC로 전송하여 생산라인 상태를 한 화면에서 모니터링할 수 있도록 구현했습니다.

동시에 VS Code 환경에서 C 언어와 JSON 포맷을 이용해 TCP/IP 채팅 프로그램을 제작하고, 현장 운영자와 관제 PC 간의 간단한 메시지 교환이 가능하도록 연동했습니다. 서버와 클라이언트는 {"name":"사용자","message":"내용"} 형태의 JSON 메시지를 주고받도록 설계하여 디버깅과 로그 분석을 쉽게 했습니다.

WinForm 기반 대시보드에서 생산라인 상태와 알림 메시지를 함께 확인할 수 있어, 모니터링과 커뮤니케이션을 하나의 통합 시스템으로 구성한 것이 특징입니다.

PC에서 생산라인 전체 상태를 한눈에 볼 수 있도록 WinForm으로 전용 대시보드를 개발했습니다. 각 설비의 상태, 온도, 습도, 화재 감지 여부를 실시간 값으로 표시하고, 경고 발생 시 색상과 알림 메시지로 즉시 확인할 수 있도록 구성했습니다.

라즈베리파이에서 전송하는 카메라 영상은 LibVLC를 이용해 WinForm 내부에서 바로 재생되도록 했으며, 설비 제어 신호는 Modbus와 MQTT 통신으로 PLC 및 라즈베리파이와 연동했습니다. 이를 통해 모니터링과 제어 기능을 하나의 화면에서 통합해 운영자가 직관적으로 사용할 수 있는 HMI 형태로 구현했습니다.

디팔렛타이저 로봇 팔 제어

Arduino Mega
Servo
PLC 연동

YOLO 기반 객체 인식과 딥러닝을 활용해 수납장의 빈 공간을 자동으로 확인하고, 아두이노 카에 목표 물체 4개가 적재되면 출발하여 디팔렛타이저를 통해 수납장에 입고되도록 구성했습니다. 또한 웹 서버에서 출고 명령을 받으면, 라즈베리파이에 연결된 카메라가 다시 YOLO 객체 인식을 수행해 지정된 품목을 찾아 자동으로 출고할 수 있도록 구현했습니다.

6축 서보 모터를 사용한 디팔렛타이저 로봇 팔을 제작하여 박스를 정해진 위치로 자동 적재하는 기능을 구현했습니다. 조이스틱으로 각 관절을 수동 제어하고, 미리 저장한 각도 시퀀스로 자동 동작도 수행합니다.

서보 전원과 제어 신호를 분리하여 안정성을 확보하고, PLC와 연동해 시작/정지, 비상 정지 신호를 주고받도록 구성하여 실제 생산라인 환경에 가까운 제어 구조를 연습했습니다.

MQTT & PLC 기반 화재 감지 알림 시스템

Raspberry Pi
MQ-2 Sensor
MQTT
PLC
WinForm

가스 센서 MQ-2를 이용해 일정 농도 이상의 연기·가스가 감지되면 라즈베리파이가 MQTT 메시지를 발행하고, PC와 PLC에서 이를 구독해 알림을 표시하는 화재 감지 시스템을 구현했습니다.

PLC에는 화재 상태를 나타내는 코일/레지스터를 두어, 라즈베리파이에서 전달된 정보에 따라 화재 경보 출력이나 경광등 제어가 가능하도록 했습니다. PC WinForm 프로그램에서는 MES기반 프로그램을 만드는것을 목표로 MQTT 메시지와 PLC 상태를 동시에 모니터링하여, 화면 색상과 팝업으로 화재 상황을 직관적으로 표시하도록 구성했습니다.

C++ 미니게임 모음 프로젝트

C++
Visual Studio
콘솔 게임

Visual Studio를 사용해 여러 개의 간단한 콘솔 미니게임을 하나의 프로젝트로 통합했습니다. 메뉴에서 게임을 선택하면 해당 게임이 실행되는 구조로 설계하고, 포인터, 구조체, 함수 분리, 헤더 파일 분할 등 C++의 핵심 문법을 적극적으로 활용했습니다.

공용으로 사용하는 게임 유틸 함수(입력 처리, 화면 갱신 등)를 별도의 모듈로 분리하여, 코드 중복을 줄이고 유지보수성을 높였습니다. 이를 통해 절차적 프로그래밍에서 구조화된 설계로 확장하는 연습을 할 수 있었습니다.

달력 기반 일정 관리 프로그램

C#
WinForm
일정 관리

WinForm의 MonthCalendar 컨트롤을 기반으로 날짜별 일정을 관리할 수 있는 프로그램을 구현했습니다. 사용자가 달력에서 날짜를 선택하면 오른쪽 패널에 해당 날짜의 일정 목록이 표시되고, 새로운 일정을 추가·수정·삭제할 수 있도록 구성했습니다.

일정 데이터는 로컬 파일로 저장·불러오기 기능을 구현하여 프로그램을 다시 실행해도 이전에 등록한 일정이 유지되도록 했습니다. 이 과정에서 폼 간 데이터 전달, 이벤트 처리, 리스트 갱신 로직 등을 직접 구현하며 데스크톱 애플리케이션 구조를 자연스럽게 익혔습니다.

PC방 스타일 WinForm 화면 개인 프로젝트

C#
WinForm
UI 디자인

PC방 관리 프로그램을 콘셉트로 한 WinForm 기반 개인 프로젝트입니다. 사용자가 로그인하면 남은 시간, 사용 요금, 인기 게임 목록 등을 한 화면에서 확인할 수 있도록 UI를 구성했습니다.

좌석 정보, 게임 실행 버튼, 공지 영역 등을 패널로 나누어 배치하고 버튼 색상, 폰트, 정렬 등 UI 요소를 직접 디자인하면서 실사용 프로그램에 가까운 화면 구성을 연습했습니다. 추후에는 실제 시간 차감 로직과 요금 계산 기능까지 확장할 수 있도록 구조를 설계해 두었습니다.
