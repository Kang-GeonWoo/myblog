스마트 베이커리 모니터링과 채팅 연동까지

2025-12-05

스마트 베이커리 프로젝트에서는 라즈베리파이 4대를 이용해 오븐, 냉동고, 포장 구역에 카메라와 센서를 설치하고 Flask 서버로 영상을 모아 WinForm 대시보드에서 한 번에 모니터링할 수 있도록 구성했다.

현장 운영자와 관제 PC 간 소통을 위해 VS Code에서 C 언어와 JSON 포맷을 이용한 TCP/IP 채팅 프로그램도 만들었다. {"name":"사용자","message":"내용"} 형태로 메시지를 주고받도록 설계해 사람이 읽기 쉬운 로그를 남길 수 있었고, 생산라인 모니터링과 커뮤니케이션을 하나의 흐름으로 통합한 경험이 인상적이었다.

디팔렛타이저 서보 모터 전원 구성과 안정화

2025-12-02

디팔렛타이저 로봇 팔에는 MG996R 서보를 6개 사용했다. 처음에는 아두이노 메가 보드에서 전원을 직접 공급했는데, 부하가 몰리면 전압이 떨어지면서 보드가 리셋되는 문제가 발생했다.

이를 해결하기 위해 5V 10A 어댑터로 서보 전원을 따로 공급하고, 아두이노와는 GND만 공통으로 연결했다. 또, 모든 관절을 동시에 크게 움직이는 대신 동작 순서를 약간씩 지연시켜 토크를 분산함으로써 전류 피크를 줄일 수 있었다.

Flask 서버로 라즈베리파이 영상 스트리밍하기

2025-11-29

라즈베리파이에서 OpenCV로 캡처한 프레임을 JPEG로 인코딩한 뒤, HTTP POST 요청으로 Flask 서버의 /upload/<cam_id> 엔드포인트에 전송하도록 구현했다.

서버에서는 최신 프레임을 메모리에 저장해 두었다가 /stream/<cam_id> 요청이 들어오면 MJPEG 스트림으로 계속 내려보내 브라우저와 WinForm에서 실시간 영상처럼 볼 수 있게 했다. 이 구조를 통해 카메라 수가 늘어나도 같은 패턴으로 쉽게 확장할 수 있었다.

MQTT와 PLC를 이용한 화재 감지 알림 구조

2025-11-20

MQ-2 가스 센서 값을 라즈베리파이에서 읽어, 기준값을 넘으면 MQTT 토픽 factory/fire 로 화재 상태를 전송하는 구조를 만들었다. PC와 PLC는 이 토픽을 구독해 각각 화면 알림과 출력 제어를 담당한다.

PLC에는 화재 상태를 나타내는 코일과 레지스터를 두어 라즈베리파이에서 전달된 정보에 따라 경보등, 부저 등의 출력이 동작하도록 했다. WinForm에서는 MQTT 메시지와 PLC 상태를 동시에 보여줘, 어디서 이상이 발생했는지 한 번에 확인할 수 있게 했다.

C++ 미니게임 프로젝트에서 배운 모듈화

2025-11-10

여러 개의 콘솔 미니게임을 하나의 C++ 프로젝트로 묶으면서 포인터, 구조체, 헤더 파일 분리 같은 기본기를 많이 복습했다. 공통으로 사용하는 랜덤 초기화, 입력 처리, 화면 초기화 함수 등은 별도의 유틸 모듈로 분리해 두고 각 게임에서 가져다 쓸 수 있게 했다.

이렇게 구조를 나누어 보니 나중에 새로운 게임을 추가할 때도 메뉴에만 선택지를 하나 더 넣고, 게임 로직만 별도 파일로 작성하면 되는 형태가 되어 확장성이 좋아졌다.

WinForm 달력 기반 일정 관리 프로그램 만들기

2025-11-05

MonthCalendar 컨트롤을 중심으로 날짜별 일정을 관리하는 WinForm 프로그램을 만들었다. 달력에서 날짜를 클릭하면 오른쪽 리스트에 해당 날짜의 일정이 표시되고, 아래 텍스트 박스에서 새 일정을 추가·수정·삭제할 수 있다.

일정 정보는 로컬 파일로 저장해 프로그램을 다시 실행해도 데이터를 유지하도록 했고, 폼 로드/닫기 이벤트에 저장·불러오기 로직을 연결하면서 데스크톱 앱의 기본 생명주기를 익힐 수 있었다.

PC방 스타일 WinForm 화면 UI 실험

2025-10-30

개인 프로젝트로 PC방 관리 프로그램 느낌의 WinForm 화면을 구성해 봤다. 좌석 번호, 사용 시간, 요금 정보, 인기 게임 목록, 공지 영역 등을 패널로 나누어 배치하고 색상과 폰트를 조정해 실제 PC방 클라이언트 비슷한 분위기를 내는 것이 목표였다.

아직은 로그인, 시간 차감, 요금 계산 로직만 기본적으로 넣어 둔 상태지만, 화면 설계를 직접 해보면서 버튼과 패널의 역할 분리, 폼 간 이동 구조 등 UI 쪽 감각을 많이 익힐 수 있었다.
